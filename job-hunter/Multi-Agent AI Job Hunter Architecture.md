# Архитектура Multi-Agent AI Job Hunter: взаимодействие Discord, Docker, Switch Rooms и CLI-агентов

Данный документ описывает полную логику работы и взаимодействия всех компонентов системы автоматизированного поиска работы, включая место подключения языковых моделей и программ-агентов (**Antigravity**, **Open Code**, **Claude Code**).

---

## 1. Общая формула архитектуры

Вся система строится на связке из четырёх ключевых уровней, где каждый элемент отвечает за строго определённую задачу:

$$\text{Discord (Пульт управления)} \longleftrightarrow \underbrace{\text{Switch Rooms + PostgreSQL (в Docker)}}_{\text{Диспетчер и база данных}} \longrightarrow \underbrace{\text{CLI-агент (Antigravity / Open Code)}}_{\text{Мозг + LLM на вашем ПК}} \longrightarrow \text{Node.js скрипты (Инструменты)}$$

## 2. Разбор каждого звена системы

### 1. Discord — Удалённый пульт управления (Интерфейс)

- **Роль:** Единственная точка общения пользователя с командой агентов.
- **Как работает:** Вы пишете команды и сообщения в основном канале (например, `#job-hunt`) или в отдельных тредах под конкретные вакансии.
- **Особенности:** Не требует открытия портов, белого IP или утилит вроде `ngrok`. Связь идёт через исходящее WebSocket-подключение (Gateway API) по токену вашего приватного Discord-бота.

### 2. Docker-контейнер (Switch Console + PostgreSQL) — Диспетчер

- **Роль:** Координационный центр, который связывает сообщения из Discord с агентами на вашем компьютере.
- **Из чего состоит:**
  - **Switch Rooms (Switch Console):** Локальный сервер управления агентами и комнатами.
  - **PostgreSQL:** Локальная база данных внутри контейнера, где хранятся настройки комнат, общие документы (`Resume`, `Preferences`), системные инструкции агентов и история их взаимодействия.
- **Важный нюанс:** У самого Switch Rooms **нет встроенной нейросети**. Он выступает исключительно как диспетчер (маршрутизатор задач).

### 3. Программа-агент (Antigravity / Open Code / Claude Code) — «Мозг»

- **Роль:** Исполнительный модуль, который умеет «думать», обращаться к языковым моделям (LLM), читать файлы и запускать скрипты в терминале.
- **Где настраивается:** Подключается непосредственно в панели управления **Switch Console** при создании или редактировании каждого агента (`Your Agents` $\rightarrow$ `+`):
  1. **Run location (Место запуска):** Выбирается вариант `This computer` (на вашем локальном ПК).
  2. **Agent Provider (Провайдер агента):** В выпадающем списке указывается установленная у вас программа — **Antigravity**, **Open Code**, **Claude Code** или **Gemini CLI**.
  3. **Directory (Рабочая папка):** Указывается путь к локальной папке проекта `job-hunter/`.
- **Где выбирается нейросеть:** Конкретная LLM (например, бесплатные модели Gemini 3.1 Flash/Pro через Google-аккаунт или модели через OpenRouter) настраивается **внутри самой выбранной программы-агента** (в настройках Antigravity или Open Code), а не в скриптах репозитория.

### 4. Локальная папка проекта и Node.js скрипты (`.mjs`) — «Инструменты»

- **Роль:** Набор готовых инструментов из GitHub-репозитория, которые лежат в обычной папке на вашем компьютере.
- **Состав:**
  - `scripts/` — скрипты без тяжелых зависимостей для поиска вакансий (`search-jobs.mjs`), проверки актуальности (`check-posting.mjs`), поиска контактов (`hunter.mjs`), рендеринга HTML в PDF через Puppeteer (`make-pdf.mjs`), генерации ссылок Gmail (`links.mjs`) и учёта статусов (`tracker.mjs`).
  - `jobs/<company>-<role>/` — папки под каждую вакансию с готовыми резюме (`resume.html`, `resume.pdf`), описаниями (`job.md`) и списком контактов (`people.json`).
  - `.env` — локальный файл с API-ключами (изолирован от чтения агентами через правила безопасности).

## 3. Пошаговый цикл обработки запроса (от сообщения до результата)

1. **Сигнал из чата:** Вы отправляете команду в канал или тред Discord (например, тегаете `@scout` или подтверждаете этап словом `approved`).
2. **Перехват диспетчером:** Контейнер **Switch Rooms** в Docker принимает событие от Discord через бот-токен и сохраняет контекст в **PostgreSQL**.
3. **Запуск агента на ПК:** Switch проверяет настройки вызванного агента (`Run location: This computer`, `Agent Provider: Antigravity / Open Code`) и запускает локальный процесс этой программы, передавая ей текст вашего сообщения, общие правила комнаты и инструкцию самого агента.
4. **Работа с LLM и файлами:** Запущенный **Antigravity** (или **Open Code**) обращается к подключённой внутри него нейросети, анализирует задачу, запускает нужные скрипты из папки `scripts/` и сохраняет готовые файлы (например, `resume.pdf`) в папку `jobs/`.
5. **Возврат ответа:** Программа-агент возвращает текстовый отчёт и прикреплённые файлы обратно в **Switch Rooms**, который публикует их от имени бота в нужный тред Discord.

## 4. Сводная таблица распределения ролей

| Компонент                     | Где находится                     | Основная функция                                                                        |
| :---------------------------- | :-------------------------------- | :-------------------------------------------------------------------------------------- |
| **Discord**                   | Облако / Клиент на ПК и смартфоне | Удобный чат-интерфейс, одобрение шагов (Human-in-the-loop) и просмотр результатов.      |
| **Switch Rooms + PostgreSQL** | Локально в **Docker-контейнере**  | Связь с Discord, хранение промптов, документов комнаты и маршрутизация задач.           |
| **Antigravity / Open Code**   | Установлено локально на вашем ПК  | «Мозг» системы: связь с облачной/бесплатной LLM и выполнение команд в системе.          |
| **Репозиторий `job-hunter`**  | Локальная папка на вашем ПК       | Готовые `.mjs` скрипты, шаблон резюме, база трекера `tracker.json` и готовые PDF-файлы. |
